# Fénix Cafés (site)

Site estático, sem build. Abrir `index.html` por um servidor local, por exemplo:

    npx serve .

Antes de publicar: definir `WA_NUMBER` (só dígitos com indicativo, ex. `"351912345678"`) no fim de `index.html`.
Preços e dados dos blends estão no objeto `BLENDS` (e no HTML de cada sala).
Motor de scroll: scrollcraft (MIT). Fontes: Poppins e Kaushan Script (OFL), alojadas em `assets/fonts`.
