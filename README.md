# task-observer

## Superpowers

Este repositório inclui a biblioteca de skills [Superpowers](https://github.com/obra/superpowers) (MIT, © Jesse Vincent), instalada como skills de projeto do Claude Code.

- Skills: `.claude/skills/` (versão upstream: `8ca22db`)
- Hook de arranque: `.claude/hooks/superpowers-session-start.sh`, registado em `.claude/settings.json` — injeta a skill `using-superpowers` no início de cada sessão.

Para atualizar, copiar de novo a pasta `skills/` do repositório upstream para `.claude/skills/`.
